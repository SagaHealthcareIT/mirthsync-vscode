# Security policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email **security@saga-it.com** with:

- A description of the issue and its potential impact.
- The extension version where you observed it (Settings → Extensions → MirthSync).
- Reproduction steps, including a minimal sample workspace if applicable.
- Whether you'd like to be credited in the release notes when the fix ships.

We will acknowledge receipt within two business days and aim to provide a remediation timeline within five.

## Scope

This policy covers the MirthSync VS Code extension as published on the VS Code Marketplace (`SagaITLLC.mirthsync`) and Open VSX. The Mirth Connect server, the `mirthsync` CLI, and Open Integration Engine are maintained separately and have their own security contacts.
